# Product Context: ClipForge

## Problem Statement
Video editing on desktop is either too complex (Adobe Premiere, Final Cut) or too limited (basic trimming apps). Creators need a middle ground—something powerful enough for serious work but simple enough to use in minutes.

## Solution
ClipForge is a desktop video editor that brings the intuitive mobile video editing experience to desktop. Built for quick screen recordings, product demos, tutorial videos, and social content.

## Target Users
- **Content Creators**: Need quick screen recordings for YouTube/TikTok
- **Educators**: Record lectures and add annotations
- **Professionals**: Product demos and presentations
- **Social Media Managers**: Quick video posts and stories

## User Stories

### Recording
"As a user, I want to record my screen with webcam overlay so I can create engaging tutorial content."

"As a user, I want to record just my webcam so I can add talking-head segments."

"As a user, I want to stop and re-record segments easily."

### Import & Organization
"As a user, I want to drag video files into the app so I can quickly start editing."

"As a user, I want to see thumbnails of my clips so I can identify content visually."

"As a user, I want to import multiple clips at once."

### Editing
"As a user, I want to trim clips on a timeline so I can cut out mistakes."

"As a user, I want to split clips so I can rearrange segments."

"As a user, I want to see a preview of my edits in real-time."

### Export
"As a user, I want to export to MP4 so I can share anywhere."

"As a user, I want to see export progress so I know how long it will take."

## User Experience Principles
1. **Fast**: Everything happens in real-time or near-real-time
2. **Intuitive**: Timeline interactions match mental models
3. **Reliable**: No crashes, smooth playback, clear errors
4. **Focused**: Essential features only, no bloat

## Success Metrics
- User can complete a full edit in under 5 minutes
- Import takes under 2 seconds
- Timeline scrolling is smooth at 60fps
- Export completes without crashing
- App can handle 20+ clips without performance issues

## Design Philosophy
"Make the common case fast, and everything else possible."

Common case: Record screen → Trim → Export

Everything else: Multi-track, effects, overlays, audio mixing
